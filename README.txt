NULLRITE / DREW SHINHEARTS NFC BUSINESS CARD

1. Create a public GitHub repository named nullrite-card (or another name).
2. Upload index.html, style.css, favicon.svg, and drew-shinhearts.vcf to the repository root.
3. In repository Settings > Pages, choose Deploy from a branch, main, /(root), Save.
4. Wait for GitHub Pages to publish. The URL will usually be https://shinhearts.github.io/nullrite-card/
5. Open the published URL on your phone and test the Save Contact button.
6. In Bruce 1.17: RFID > Write NDEF > URL; enter the exact published URL; present NTAG215.
7. Test the NFC card with your iPhone. The card should open the site, where Save Contact downloads a VCF.

Before publishing, review public contact info. Phone number intentionally omitted.
GitHub profile included: https://github.com/shinhearts
